Список задач на HTML, CSS, JavaScript, Node.js, Express и MySQL. Можно добавлять задачи, отмечать их выполненными, удалять и фильтровать список. Все изменения сохраняются в локальной базе данных MySQL и доступны после обновления страницы.

## Запуск через Docker

1. Установите и запустите Docker Desktop.
2. При необходимости скопируйте `.env.example` в `.env` и замените демонстрационные пароли. Примерные пароли предназначены только для локального запуска; задайте свои до первого запуска базы.
3. В терминале из папки `todo-list` запустите:

   ```powershell
   docker compose up --build -d
   ```

4. Откройте <http://localhost:3000>.

Docker Compose запускает веб-сайт с API и MySQL 8.4. Данные базы хранятся в именованном томе `todo-list-mysql`; перезапуск или пересборка контейнеров их не удаляют. Для проверки состояния выполните `docker compose ps`, для просмотра логов — `docker compose logs -f app db`.

Чтобы остановить приложение, выполните `docker compose down`. Данные сохраняются; команда `docker compose down -v` удалит том и все сохранённые задачи.

## Запуск без Docker

Нужны Node.js 20+ и локальный MySQL 8.4. Создайте базу `todo_list`, установите зависимости командой `npm install` и запустите сервер командой `npm start`. При необходимости задайте переменные окружения `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` и `PORT`. Таблица создаётся приложением при запуске.

## API

- `GET /api/tasks` — получить задачи.
- `POST /api/tasks` с JSON `{"title":"Текст задачи"}` — добавить задачу.
- `PATCH /api/tasks/:id` с JSON `{"completed":true}` — изменить статус выполнения.
- `DELETE /api/tasks/:id` — удалить задачу.
- `DELETE /api/tasks/completed` — удалить все выполненные задачи.

Проверки API запускаются командой `npm test`.
